Naming rules

Use lowercase only
Use hyphens instead of spaces
Never repeat a filename inside the same folder
Use cover.jpg for the main project thumbnail
Number all extra images like -01, -02, -03

Good:
walk-in-gun-metal-01.jpg

Bad:
Walk In Closet Final (1).jpg
